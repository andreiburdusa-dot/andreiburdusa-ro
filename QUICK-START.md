# ⚡ Quick Start — 30 secunde

## Pașii:

1. **Deschide** `/path/to/andreiburdusa-ro/` folder
2. **Copie** `index.html` din ZIP-ul ăsta peste `index.html` curent
3. **Terminal**:
   ```bash
   cd /path/to/andreiburdusa-ro
   git add index.html
   git commit -m "Add Flux Viv"
   git push origin principal
   ```
4. **Asteaptă** 30 secunde
5. **Verifi** https://andreiburdusa.ro (trebuie 4 coloane sub hero)

**GATA.**

## De acum înainte:
